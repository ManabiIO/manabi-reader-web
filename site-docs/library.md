# Your library

Use **Search** to find a book. **Library actions** → **View Options** changes the grid or list layout, sorting, and filters. On a wide screen, collections appear in the sidebar; on a narrow screen, open **Collections** from the top bar.

## Make a collection

Open **Collections**, then create a collection. Add books from a book's ellipsis menu. A book can belong to more than one collection; collections do not move its file.

**Books** shows available books. **Finished** shows books you marked as finished. If a source is disconnected, its books are hidden from collection counts until it is available again.

## Group books into a series

Folders with several books appear as series, including nested folders. A single-book wrapper stays visually flat. To make a series from books in a writable local folder, select them and choose **Organize Library** → **Create Series from Books**. This moves the original files into a new folder.

Cloud libraries can be browsed, but creating folders or moving their original files from the reader is not available yet.

## Change a book

Use its ellipsis menu to rename its display title, set a cover override, add it to a collection, or mark it as finished. These presentation changes do not rewrite the ebook. Removing a book from this browser does not delete its source file.
