# Manabi Reader for Web versus Ttsu Reader

[ッツ Ebook Reader](https://github.com/ttu-ttu/ebook-reader), often called **Ttsu Reader** or **TTU Reader** (and sometimes written **TTSU**), is the open-source reader from which this project was forked. Both support EPUB, HTMLZ, and text books, flexible reading layouts, bookmarks, statistics, and offline-capable use.

| If you want to…                | Manabi Reader for Web                                | Ttsu Reader                                     |
| ------------------------------ | ---------------------------------------------------- | ----------------------------------------------- |
| Organize a personal library    | Collections, finished books, and folder-based series | Book manager                                    |
| Read from connected sources    | Local folders and supported cloud libraries          | Local and external storage options              |
| Keep familiar reading controls | Vertical or horizontal, continuous or paginated      | Vertical or horizontal, continuous or paginated |
| Move existing Ttsu data        | Import a Ttsu export with a preview                  | Export its reading data                         |

Choose Ttsu if you prefer its established, lightweight reader. Choose Manabi Reader for Web for a more developed personal library and optional Manabi account sync. Ttsu's [feature list](https://github.com/ttu-ttu/ebook-reader#features) is the source for its capabilities here.
