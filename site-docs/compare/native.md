# Manabi Reader for Web versus Manabi Reader for iOS and macOS

The web reader is an independent open-source project, not a port of the native Manabi Reader apps. It builds on an existing web reader and is developing its own library and reading experience. The native apps currently offer much more for Japanese study.

| If you want to…        | Web                                                | iOS and macOS                                                   |
| ---------------------- | -------------------------------------------------- | --------------------------------------------------------------- |
| Read your ebooks       | In a modern browser, including non-Apple platforms | In dedicated Apple-platform apps                                |
| Look up Japanese words | Use a browser dictionary extension                 | Tap or click a word for contextual results from a custom parser |
| Track learning         | Reading progress and statistics                    | Reading plus word and kanji knowledge over time                 |
| Make flashcards        | Not yet available                                  | Anki and Manabi flashcard workflows                             |

If you use an Apple device, consider the [native Manabi Reader apps](https://manabi.io/). They are optional; the web reader is a free and open-source project in its own right.

## Can I use them together?

Not yet. Web and native libraries, progress, and study data do not currently synchronize with each other. Work toward interoperability and bringing more native reading tools to the web is under way; it is not a feature you should depend on today.
