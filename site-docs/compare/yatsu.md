# Manabi Reader for Web versus Yatsu Reader

[Yatsu Reader](https://docs.yatsu.moe/) is another reader built from Ttsu. Both projects read EPUB, HTMLZ, and text books, and offer library organization, reading statistics, and sync options. Their emphasis differs.

| If you want to…             | Manabi Reader for Web                                         | Yatsu Reader                                                                         |
| --------------------------- | ------------------------------------------------------------- | ------------------------------------------------------------------------------------ |
| Manage books                | Collections, finished books, and directory-backed series      | Library organization and reader tools                                                |
| Read from cloud storage     | Browse connected Google Drive, Dropbox, or OneDrive libraries | Its own storage and sync options                                                     |
| Use language-specific tools | Works with browser dictionary extensions                      | More built-in language and integration options, including Chinese and Korean support |
| Move reading data           | Backup import/export and Ttsu import                          | Its own import/export workflow                                                       |

Yatsu may suit you better if its [language tools and integrations](https://docs.yatsu.moe/why-yatsu/) are central to your reading. Manabi Reader for Web focuses on a compact personal library and its path toward the broader Manabi reading tools. Neither project's data export should be assumed to import directly into the other.
