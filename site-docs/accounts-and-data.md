# Accounts and data

Books you import into the browser stay there until you remove them or clear the browser's site data. Keep a copy of the original ebook files.

From **Library actions** → **Accounts and Libraries**, you can connect a local folder or a supported cloud library. Cloud sources let the reader browse the original files. OneDrive series editing, when offered by the connected server, requires additional permission and a separate preview and confirmation before it changes original files. Connecting a source does not turn on account sync.

A Manabi account is optional. If you turn on sync, supported settings and reading data can follow you between web installations. Collections and book presentation overrides use book content identities where available, so a known book can retain them when its source path changes. A source that is unavailable remains referenced but does not appear in the visible collection count.

To make a portable copy, open **Library actions** → **Select Books**, select the books, and choose **Export**. You can import a backup from **Library actions** → **Add Books** → **Import Backup**. Check the export choices before replacing local data on another device.

The web and native Manabi Reader apps do not yet share a library or reading state. See [the app comparison](compare/native.md).

## Offline edits and history

Local reading changes remain in this browser while it is offline. When an older
installation reconnects after account history has been compacted, it first reads
the current account copy and reconciles its pending edits. Conflicting changes
still need your choice; a missing or reset account feed does not silently erase
local reading data. Keep exported backups before clearing browser storage.

Account limits apply to current personal data, not the number of times you have
synced. If that space is full, new edits remain saved locally and deleting
unneeded account data can free capacity.

## OneDrive series changes

Checking a selection does not move files. Review the completed preview, then
confirm once. Confirmed work continues even if you close the dialog or browser.
The saved change status shows progress and any reconciliation. A paused change
can be abandoned after review, but completed moves are not undone.
