# Read a book

Open a cover to resume where you left off. Use the reader controls to open the table of contents, add a bookmark, or jump to a position.

In **Settings**, you can change the theme, text size, font, page layout, and reading direction. The reader supports horizontal and vertical text, and continuous or paginated reading. Some controls depend on the book format and browser.

Progress is saved as you read. Use the book menu to **Mark as Finished** and, if you want, set its finished date. **Statistics** shows your reading history.

Dictionary browser extensions such as Yomitan can work with selected text. The web reader does not yet have the native Manabi apps' built-in Japanese parser, word knowledge tracking, or flashcard workflow.
